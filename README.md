# Киноманьяк

**Достигнутые уровни:** Common

Программа подбирает 1–3 фильма под сложный запрос и предлагает **только** фильмы из локального каталога `films.json`. Модель возвращает `film_id` и `why`; название, год, длительность и описание печатает код из каталога.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и ключ OpenAI.

```bash
uv sync
cp .env.example .env   # впишите OPENAI_API_KEY
uv run kino.py "что посмотреть с мамой на казахском, до двух часов"
uv run show.py
uv run check.py
uv run pytest -q
```

Модель по умолчанию: `gpt-6-luna` (как в лекции 3). Локально: `uv run kino.py "…" --local` (Ollama `qwen3.5:4b`, `reasoning_effort=none`).

## Каталог

- `films.json`: 56 фильмов, из них 10 с `countries`, содержащим «Казахстан».
- Год и длительность сверены с карточными данными TMDB / Кинопоиска / Википедии (снимок на ноябрь 2026).
- Каталог **не** собран из памяти модели. Канон жанров/языков/стран — в `canon.py` (задел под Epic).
- Обновление: новый снимок в git; `pick` не ходит в TMDB на каждый запрос.

## Пять вопросов лекции 1

1. **Цель.** Дать безопасный ответ на сложный запрос о кино без выдуманных фильмов.
2. **Без ML.** Правила + фильтры по полям каталога (язык, минуты, жанр). Не хватает понимания «как Интерстеллар, но не про космос».
3. **Данные.** Локальный `films.json` (id, title, year, minutes, genres, countries, languages, description).
4. **Выдаёт.** 1–3 карточки из каталога или `no_match` / сообщение об ошибке; журнал `calls.jsonl`.
5. **Цена ошибки.** Показать несуществующий фильм (как список книг Chicago Sun-Times) — доверие потеряно; поэтому id сверяет код.

## Как устроены проверки

1. Промпт: весь каталог в `<каталог>`, запрос в `<запрос>`; теги = данные; один пример.
2. Схема Pydantic `Choice` (`ok` | `no_match`, `picks[{film_id, why}]`) через `chat.completions.parse`.
3. Код: allow-list id, без повторов, ≤3; чужой id → `invalid` + `rejected`.
4. Ошибки API / refusal / length / ValidationError не роняют процесс.
5. `queries.json` (17 запросов) + `check.py`; pytest с заглушкой клиента.

## Опыт с памятью модели (п.10 инструкции)

Без каталога модель `gpt-6-luna` угадала год и длительность для 10 фильмов из `films.json`.  
Сверка кодом: **4 расхождения из 10** (см. `memory_probe.json`: kz-002 minutes, kz-004 minutes±1, kz-007 year/minutes, kz-008 year/minutes).  
Именно поэтому печать идёт из каталога, а не из ответа модели.

## Ответы на вопросы задания

1. **Почему id, а не название?** Названия неоднозначны и легко галлюцинируются; id однозначно бьётся с каталогом. Опыт памяти: **4/10** расхождений — `memory_probe.json`, сверка в том же скрипте. Код печати: `kino.py` → `print_films`.
2. **Чужой film_id.** Пользователь фильм не видит; исход `invalid`, id в `rejected`. Ловят `sanitize_picks` и ветка `if rejected` в `pick` (`kino.py`).
3. **«Без ошибки API» ≠ «верный фильм».** Схема/HTTP могут быть ок, а id — чужой или мимо `must`. В `check.py` это видно: `expect_ok` требует `must`/`forbid`/`no_match`, не только отсутствие `error_*`.
4. **Без ML.** Жёсткие фильтры по полям. На `queries.json` не хватает семантики («как Интерстеллар, но не про космос», казахские формулировки, провокации).
5. **Цена запроса.** ~$0.0006 на вызов при каталоге ~56 фильмов; доминирует **prompt_tokens** (каталог в контексте). См. `PRICE` в `kino.py` и `show.py`.
